## Submission instructions

1. **Fork** this repository to your GitHub account.
2. Choose a challenge below. Open its folder to read the problem instructions.
3. In **your fork**, open that challenge's `solution.py` file.
4. Complete the Python function named `solution`. **Keep the function name and the parameters as written.**
5. Return the requested value instead of printing it unless the challenge states otherwise.
6. Commit your changes and open a pull request from your fork's `main` branch into this repository's `main` branch.
7. Leave the pull request open; **do not merge it**. You can submit corrections by making additional commits to the same branch.

Your leaderboard points reflect coding-challenge progress, not a classroom grade.
